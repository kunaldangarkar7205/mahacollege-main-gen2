# MahaCollege 4.0 — CAP cutoff update

This package adds verified 2026-27 CAP Round 1 and CAP Round 2 percentile values into the existing cutoff rows for MGM's College of Engineering and Technology (Institute Code 03175), in addition to the existing CAP Round 4 data.

- College Details now displays CAP 1, CAP 2, CAP 3 and CAP 4 columns.
- CAP 1 and CAP 2 values are shown where the exact college + branch + category + seat-pool row was verified from the official Maharashtra CET Cell PDFs.
- CAP 3 remains `—` in this update where it has not been imported.
- CAP 4 remains the existing verified local dataset.
- The College Predictor now uses the selected CAP 1, CAP 2 or CAP 4 value when available.

Official sources:
- CAP 1: https://cappublicdocs2026.blob.core.windows.net/documents/2026ENGG_CAP1_MH_CutOff_V1.pdf
- CAP 2: https://cappublicdocs2026.blob.core.windows.net/documents/2026ENGG_CAP2_MH_CutOff.pdf
- CAP 3: https://cappublicdocs2026.blob.core.windows.net/documents/2026ENGG_CAP3_MH_CutOff.pdf
- CAP 4: https://cappublicdocs2026.blob.core.windows.net/documents/2026ENGG_CAP4_MH_CutOff.pdf
